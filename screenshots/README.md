# Screenshots (Marketplace Listing)

The Frappe Marketplace audit requires screenshots on the app listing. They are
uploaded on the listing page itself (Frappe Cloud dashboard), not read from this
repo — so this folder is a staging area: add the PNGs here, then upload the same
files to the marketplace listing.

Suggested captures (desk, 1440px wide):

1. `01-chat-panel.png` — Sales AI assistant panel answering a sales question.
2. `02-sales-dashboard.png` — Sales Dashboard page with KPIs and trend.
3. `03-playbook.png` — Sales AI Playbook form with steps graph.
4. `04-trigger.png` — Sales AI Trigger form (document event + prompt template).

Keep each file under ~1 MB. After uploading, reference them from the main
`README.md` Screenshots section.
